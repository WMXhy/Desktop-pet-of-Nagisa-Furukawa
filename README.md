# 古河渚桌宠 · Nagisa Desktop Pet

<img align="right" src="nagisa-app/src/assets/greet/002.png" width="128" alt="挥手的古河渚">

一款以《CLANNAD》古河渚为主角的非官方 Windows 桌宠。轻点渚，她会挥手向你问好。你也可以陪她逛零食店、去面包店帮工，慢慢攒够学习点，一起排练戏剧部的台词。日常玩法可以离线进行，进度保存在本机。

**[下载 Windows x64 版](https://github.com/WMXhy/Desktop-pet-of-Nagisa-Furukawa/releases/latest)** · [查看更新记录](docs/更新记录.md)

## 第一次和渚见面

1. 在发布页的 **Assets** 中下载安装包 `win-x64-Setup.exe`，双击打开。v1.0.3 起可在向导中选择安装目录。安装后从开始菜单打开 **Nagisa Desktop Pet**。下载历史便携 ZIP 时，完整解压后双击其中的 `Nagisa Desktop Pet.exe`。
2. 轻点渚打招呼并展开团子快捷菜单。「喂食」会打开头顶食物栏，左击有库存的食物喂给渚，右击可补货。「打工」「学习」和「游戏」会打开对应界面。再点一下渚或按 Esc 收起，按住角色可拖动。
3. 在手账的**活动**里选择「面包店帮工」。三分钟后可用挣到的团子币买零食或玩具。中途退出也没关系，到期的活动会在下次启动时结算。
4. 如果渚被隐藏、拖到了另一块屏幕，或开启了鼠标穿透，右击 Windows 系统托盘中的桌宠图标，选择**找回角色**。托盘图标也可能收在任务栏的折叠菜单里。

## 手账里能做什么

| 想和渚做的事 | 玩法 |
| --- | --- |
| 逛零食店 | 购买小面包、红豆面包或团子点心，放进背包或当场喂给她。新存档自带两个小面包。 |
| 安排课余时间 | 休息恢复精力，面包店帮工赚团子币；每次温习功课可获得 3 学习点。攒到 9 点开放朗读排练和整理戏剧部道具，20 点解锁专属待机语句。 |
| 玩一局小游戏 | 在「猜团子」里记住花纹团子藏在哪只碗下。买下团子玩偶后可以抱一抱或切换游戏主题，买下小舞台布景后可以玩台词接龙。 |
| 留下共同回忆 | 每天第一次轻点问候可以增加好感。达到 30、80、150 好感时依次解锁「熟悉」「信赖」「亲密伙伴」，在关系页可重看纪念对话。 |

## 桌面设置与存档

从手账或系统托盘打开**设置**。七个分类覆盖常规、外观与桌面、互动、声音与动画、提醒与专注、快捷键、存档与隐私。可以预览角色大小和所在显示器，安排跨午夜的安静时段，或让渚在其他应用全屏时暂时隐藏。

升级前，在系统托盘中选择**退出桌宠**，再运行目标版本的完整 Setup。v1.0.3 起会记住已安装的目录，也可以在升级时换位置。同一 Windows 账户继续使用原有进度。换电脑前，在**设置 → 存档与隐私**导出存档，在新电脑从同一页导入。导出内容包含养成进度和可迁移的偏好。显示器位置、全局快捷键及登录启动设置按设备配置。

## 从源码运行

项目使用 Electron、TypeScript 和 Electron Forge。Windows x64 版使用 Node.js 24.16.0 构建。从仓库根目录打开 PowerShell，执行以下命令即可启动开发版。

```powershell
cd nagisa-app
npm.cmd ci
npm.cmd start
```

退出开发版后，可以在同一目录检查类型并打包。安装 [NSIS 3.13](https://nsis.sourceforge.io/Download)，或用 `NAGISA_MAKENSIS` 指向同版本的 `makensis.exe`。Windows x64 安装器生成在 `out/release/v版本号/`。

```powershell
npm.cmd run typecheck
npm.cmd run release:windows
```

修改玩法、桌面行为或存档格式前，可先查阅[项目现状与维护交接](docs/项目现状与维护交接.md)。其中列出了源码入口、存档兼容范围和各项实测结果。分阶段实施与验收步骤见[开发指南目录](docs/)。
