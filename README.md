# 古河渚桌宠

古河渚会在 Windows 桌面眨眼。轻点她会挥手问候，按住她可拖动，重开后会恢复上次的位置。

右击系统托盘中的「古河渚桌宠」图标，可以打开手账、隐藏角色、切换鼠标穿透、找回角色或退出。图标也可能出现在托盘的折叠菜单里。「找回角色」会取消鼠标穿透，让渚回到主屏右下角。

手账可查看团子币、饱食、精力、心情和好感。新存档有两个小面包，点击「喂给渚」会提高饱食并保存进度。

手账的「活动」区可以安排 5 分钟休息或 3 分钟面包店帮工。活动到点后自动结算，退出期间结束的活动会在下次启动时结算，收益可在最近记录里查看。

手账的「零食店」可用团子币购买小面包、红豆面包和团子点心。买到的零食会存入背包，也可以点「现在喂给她」。饱食低于 15、余额不足 6 币且食物全部吃完时，可在背包领取一个应急小面包。

「温习功课」每次需要 3 分钟，完成后获得 3 学习点。累计 9 点开放「朗读排练」和「整理戏剧部道具」，累计 20 点可在手账查看专属待机语句，也可以在渚空闲时轻点她，让她用气泡说出这句台词。

在手账点「和渚玩猜团子」，记住花纹团子的位置，盖碗后选一只碗。开始一局消耗 3 精力，猜中加 5 心情，猜错加 3 心情，完成一局最多加 1 好感。

手账的「玩具店」出售两件永久玩具。团子玩偶售价 25 币，买下后可在背包里抱一抱，也能选择猜团子的玩偶主题。小舞台布景售价 45 币，买下后可以和渚玩台词接龙。

每天第一次轻点渚问候，可获得 1 好感，计入每日最多 12 点的上限。累计 30、80、150 好感会依次解锁「熟悉」「信赖」「亲密伙伴」，可以在手账的「关系」页查看记录、听渚练台词或重看纪念对话。

## 本地运行

在 Windows 上安装 Git 和 Node.js LTS，然后从仓库根目录运行：

```powershell
Set-Location '.\nagisa-app'
npm.cmd start
```

新克隆仓库后，在 `nagisa-app` 里先运行一次 `npm.cmd ci`。首次启动会下载 Electron 运行环境。

修改代码后，退出桌宠并重新运行 `npm.cmd start`。
