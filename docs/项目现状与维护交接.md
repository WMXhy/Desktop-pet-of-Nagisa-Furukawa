**Windows 本地版 1.0.0**。候选包对应源码 `6f426c3dae3bf16c290a3fb8f9c2f8512ff993f9`，Electron 45.4.1，养成存档 v6，设置 v1，导出格式 v1。[最终开发指南](10-最终开发指南.md)

## 1. 候选包

- 文件 `nagisa-app/out/make/zip/win32/x64/Nagisa Desktop Pet-win32-x64-1.0.0.zip`。
- 大小 **166,277,900 字节**，SHA-256 `2E56E98F6D720829001181A900254B70C39CB212AE43466FFC50B460987A517B`。
- 解压整份目录后运行 `Nagisa Desktop Pet.exe`。保持原应用名称，同一 Windows 用户更换程序目录时继续使用原应用数据目录。
- Forge 同时生成了 `nagisa-app/out/make/squirrel.windows/x64/Nagisa Desktop Pet-1.0.0 Setup.exe`。以下验收针对 ZIP 便携版，安装流程待单独测试。
- 构建使用 Windows x64、Node.js 24.16.0、Electron Forge 7.11.2。在独立源码目录构建以避开开发服务持有的编译文件。下载中断后，由已安装的 Electron 45.4.1 运行时构造本地 ZIP，通过 `NAGISA_ELECTRON_ZIP_DIR` 提供给 Forge。本机依赖解包停滞，隔离构建改用 Windows 自带的 `tar.exe` 完成该步骤。 [Forge ZIP maker](https://www.electronforge.io/config/makers/zip)

## 4. 复测方法

开发验证使用 `npm.cmd run typecheck` 与 `npm.cmd start`。正式候选使用 `npm.cmd run make -- --platform=win32 --arch=x64`，退出开发程序或使用独立构建目录。使用本地运行时 ZIP 时，目录中必须有与 Electron 版本、系统和架构一致的归档文件。

后续候选记录源码提交、ZIP 大小与 SHA-256、三次启动至角色可见的时间与整个 Electron 进程组的空闲 CPU、工作集。复现问题时记录入口、操作、可见结果、重启后的数值与实际 Windows 显示设置。
