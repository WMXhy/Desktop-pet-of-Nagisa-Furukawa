# 古河渚桌宠更新记录

每次更新在顶部新增一条。构建前写变更和计划验证的升级起点，验收后填入结果，公开发布后补上下载链接和哈希。下一次更新从最近的已发布条目和待办事项接续。

## v1.0.3 · Windows 安装候选

Windows x64 安装向导新增中文目录页，可安装到其他磁盘。首次默认使用 `%LOCALAPPDATA%\Programs\Nagisa Desktop Pet`，后续运行 Setup 回填原目录。养成 v6、设置 v1 和桌面位置仍从当前 Windows 账户读取。[v1.0.3 安装目录选择方案](v1.0.3-Windows安装目录选择方案.md)
