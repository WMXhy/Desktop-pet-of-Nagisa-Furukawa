## 2. 先让原来的拖动能记住位置

保留原生拖动完成本节。主进程保存**显示器 ID 和窗口左上角相对工作区的偏移**，这样副屏移到主屏另一侧时也能恢复。位置统一采用 Electron 的逻辑像素（DIP）；Windows 缩放比例无需再乘一次。[Electron 屏幕坐标与显示器事件](https://www.electronjs.org/docs/latest/api/screen)

新建 `src/pet-position.ts`：

```ts
import { app, screen, type Rectangle } from 'electron';
import { existsSync, readFileSync, renameSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';

const positionFile = () => join(app.getPath('userData'), 'pet-position.json');

export function homePosition(size: number) {
  const a = screen.getPrimaryDisplay().workArea;
  return { x: a.x + Math.max(0, a.width - size - 24),
           y: a.y + Math.max(0, a.height - size - 24) };
}

export function restorePosition(size: number) {
  try {
    if (!existsSync(positionFile())) return homePosition(size);
    const p = JSON.parse(readFileSync(positionFile(), 'utf8'));
    const display = screen.getAllDisplays().find(d => d.id === p.displayId);
    if (p.version !== 1 || !display || !Number.isSafeInteger(p.dx) ||
        !Number.isSafeInteger(p.dy)) return homePosition(size);
    const a = display.workArea;
    return {
      x: a.x + Math.max(0, Math.min(p.dx, a.width - size)),
      y: a.y + Math.max(0, Math.min(p.dy, a.height - size)),
    };
  } catch (error) {
    console.warn('位置记录无法读取，回到主屏', error);
    return homePosition(size);
  }
}

export function savePosition(bounds: Rectangle) {
  const display = screen.getDisplayMatching(bounds);
  const data = { version: 1, displayId: display.id,
    dx: bounds.x - display.workArea.x, dy: bounds.y - display.workArea.y };
  try {
    const file = positionFile();
    writeFileSync(file + '.tmp', JSON.stringify(data), 'utf8');
    renameSync(file + '.tmp', file);
  } catch (error) {
    console.warn('本次位置未保存', error);
  }
}
```

在 `src/index.ts` 导入 `homePosition, restorePosition, savePosition`。在 `startPet()` 中，用 `const { x, y } = restorePosition(size)` 替换原来的 `const area = …`，窗口选项中的两条坐标公式改成 `x, y,`，删除原来的 `margin` 常量。保留第一次开发验证过的透明窗口、`showInactive()` 和 Windows 置顶处理。

## 3. 托盘增加隐藏、穿透和找回

在 `startPet()` 内，保留原来创建 `Tray` 和设置提示文字的代码，替换原来的 `tray.setContextMenu(...)`。三个入口各自都能从系统托盘访问：

```ts
let passThrough = false;
function recoverPet() {
  passThrough = false;
  petWindow.setIgnoreMouseEvents(false);
  const { x, y } = homePosition(size);
  petWindow.setPosition(x, y);
  petWindow.showInactive();
  saveNow();
  refreshMenu();
}
function refreshMenu() {
  tray.setContextMenu(Menu.buildFromTemplate([
    { label: '隐藏角色', enabled: petWindow.isVisible(), click: () => {
      petWindow.hide();
      refreshMenu();
    } },
    { label: '鼠标穿透', type: 'checkbox', checked: passThrough, click: item => {
      passThrough = item.checked;
      petWindow.setIgnoreMouseEvents(passThrough);
    } },
    { label: '找回角色', click: recoverPet },
    { type: 'separator' },
    { label: '退出桌宠', click: () => app.quit() },
  ]));
}
petWindow.on('show', refreshMenu);
refreshMenu();
screen.on('display-removed', () => {
  const b = petWindow.getBounds();
  const visible = screen.getAllDisplays().some(({ workArea: a }) =>
    b.x >= a.x && b.y >= a.y && b.x + b.width <= a.x + a.width &&
    b.y + b.height <= a.y + a.height);
  if (!visible) recoverPet();
});
```

**检查点**：把渚拖到记事本的文字上方，开启穿透后应能选中下面的文字。“找回角色”应同时取消穿透、显示角色并回到主屏。隐藏或穿透属于本次运行的临时状态，下次启动仍可直接互动。

## 4. 让轻点和拖动共用同一个角色

现有 `.pet` 的 `app-region: drag` 会让系统接管点击。删除它和 `-webkit-app-region: drag`，保留 `draggable: false` 和 `user-select: none`，并给 `.pet` 加 `touch-action: none`。渲染层负责捕获手指或鼠标事件，主进程根据屏幕上的鼠标位移移动窗口；本次验收以 Windows 鼠标操作为准。

**第一步，接通 preload。** 将 `src/preload.ts` 的占位注释替换为下面的代码。这个接口只允许报告一次手势的阶段。[Electron IPC 与 preload](https://www.electronjs.org/docs/latest/tutorial/ipc)

```ts
import { contextBridge, ipcRenderer } from 'electron';

contextBridge.exposeInMainWorld('pet', {
  start: () => ipcRenderer.send('pet:start'),
  move: () => ipcRenderer.send('pet:move'),
  finish: (): Promise<boolean> => ipcRenderer.invoke('pet:finish'),
  cancel: () => ipcRenderer.send('pet:cancel'),
});
```

新建 `src/pet-api.d.ts`：

```ts
interface Window {
  pet: {
    start(): void;
    move(): void;
    finish(): Promise<boolean>;
    cancel(): void;
  };
}
```

**第二步，主进程判断手势。** 在 `src/index.ts` 的 Electron 导入中加入 `ipcMain`，并在 `startPet()` 创建角色窗口后、加载页面前注册以下处理。鼠标按下时记住窗口与指针的起点，一旦移动超过 5 个逻辑像素，这次手势就始终算拖动，即使最后又拖回起点。

```ts
let gesture: { pointer: Electron.Point; origin: number[]; dragged: boolean } | undefined;
function updateDrag() {
  if (!gesture) return;
  const now = screen.getCursorScreenPoint();
  const dx = now.x - gesture.pointer.x;
  const dy = now.y - gesture.pointer.y;
  if (Math.hypot(dx, dy) > 5) gesture.dragged = true;
  if (gesture.dragged) {
    petWindow.setPosition(gesture.origin[0] + dx, gesture.origin[1] + dy);
  }
}
ipcMain.on('pet:start', e => {
  if (e.sender !== petWindow.webContents) return;
  gesture = { pointer: screen.getCursorScreenPoint(),
    origin: petWindow.getPosition(), dragged: false };
});
ipcMain.on('pet:move', e => {
  if (e.sender === petWindow.webContents) updateDrag();
});
ipcMain.handle('pet:finish', e => {
  if (e.sender !== petWindow.webContents || !gesture) return false;
  updateDrag();
  const clicked = !gesture.dragged;
  gesture = undefined;
  return clicked;
});
ipcMain.on('pet:cancel', e => {
  if (e.sender === petWindow.webContents) gesture = undefined;
});
```

**第三步，连接角色图片。** 在 `src/renderer.ts` 导入 `type PointerEvent as ReactPointerEvent`（从 `react` 导入）。在文件顶层添加以下函数。下一节的 React 组件会把这些事件传给图片。

```ts
function pointerHandlers(greet: () => void) {
  return {
    onPointerDown(e: ReactPointerEvent<HTMLImageElement>) {
      if (e.button !== 0 || !e.isPrimary) return;
      e.currentTarget.setPointerCapture(e.pointerId);
      window.pet.start();
    },
    onPointerMove(e: ReactPointerEvent<HTMLImageElement>) {
      if (e.currentTarget.hasPointerCapture(e.pointerId)) window.pet.move();
    },
    async onPointerUp(e: ReactPointerEvent<HTMLImageElement>) {
      if (!e.currentTarget.hasPointerCapture(e.pointerId)) return;
      if (await window.pet.finish()) greet();
    },
    onPointerCancel() { window.pet.cancel(); },
    onLostPointerCapture() { window.pet.cancel(); },
  };
}
```

## 5. 播放眨眼、挥手和问候气泡

保留 `src/renderer.ts` 的 CSS 导入、`createRoot` 和容器检查。将 React 导入整理成下面的第一行，用七个帧导入替换原来的 `petImage` 导入。继续使用 `.ts` 文件和 `createElement`。

```ts
import { createElement as h, useEffect, useRef, useState, type PointerEvent as ReactPointerEvent } from 'react';
import open from './assets/idle_blink/000.png';
import half from './assets/idle_blink/001.png';
import shut from './assets/idle_blink/002.png';
import wave0 from './assets/greet/000.png';
import wave1 from './assets/greet/001.png';
import wave2 from './assets/greet/002.png';
import wave3 from './assets/greet/003.png';
```

在原来调用 `createRoot` 的位置加入以下组件与挂载代码。动作共用一条计时链：问候会打断眨眼，挥手结束回到睁眼；正在挥手时再次点击只保留当次问候。

```ts
function Pet() {
  const [frame, setFrame] = useState(open);
  const [bubble, setBubble] = useState(false);
  const greetRef = useRef<() => void>(() => {});
  useEffect(() => {
    let timer = 0;
    let bubbleTimer = 0;
    let waving = false;
    const later = (fn: () => void, ms: number) => {
      window.clearTimeout(timer);
      timer = window.setTimeout(fn, ms);
    };
    function play(frames: string[], delays: number[], done: () => void, i = 0) {
      if (i === frames.length) { done(); return; }
      setFrame(frames[i]);
      later(() => play(frames, delays, done, i + 1), delays[i]);
    }
    function idle() {
      waving = false;
      setFrame(open);
      if (!document.hidden) later(() => play([half, shut, half], [80, 100, 80], idle),
        3000 + Math.random() * 3000);
    }
    greetRef.current = () => {
      if (waving) return;
      waving = true;
      setBubble(true);
      window.clearTimeout(bubbleTimer);
      bubbleTimer = window.setTimeout(() => setBubble(false), 4000);
      play([wave0, wave1, wave2, wave3], [180, 180, 240, 200], idle);
    };
    function onVisibility() {
      window.clearTimeout(timer);
      window.clearTimeout(bubbleTimer);
      setBubble(false);
      idle();
    }
    document.addEventListener('visibilitychange', onVisibility);
    idle();
    return () => {
      window.clearTimeout(timer);
      window.clearTimeout(bubbleTimer);
      document.removeEventListener('visibilitychange', onVisibility);
    };
  }, []);
  return h('div', { className: 'pet-stage' },
    h('img', { className: 'pet', src: frame, alt: '古河渚', draggable: false,
      ...pointerHandlers(() => greetRef.current()) }),
    bubble && h('div', { className: 'bubble', role: 'status' }, '今天也一起加油吧。'));
}

createRoot(container).render(h(Pet));
```

在 `src/index.css` 末尾追加：

```css
.pet-stage { position: relative; width: 100%; height: 100%; }
.bubble {
  position: absolute;
  bottom: 6px;
  left: 50%;
  transform: translateX(-50%);
  white-space: nowrap;
  padding: 4px 10px;
  border-radius: 10px;
  background: #fff8ed;

  font: 14px/1.5 "Microsoft YaHei", sans-serif;

}
```

**检查点**：观察 15 秒应看到至少两次眨眼。单击时挥手约 0.8 秒、气泡约 4 秒后消失；按住拖动再松开，角色移动且不挥手。切换帧时留意脚底和头部的位置是否跳动。

## 6. 加入第一张手账面板

做一个能从托盘独立打开、关闭后不影响角色的普通窗口。第一张面板展示角色名字和桌面互动说明，下一次开发再从养成存档接入真实状态与背包。

在 `startPet()` 中定义下面的函数，在 `refreshMenu()` 的菜单项里加入 `{ label: '打开手账', click: openJournal },`。手账沿用同一渲染入口，用 URL 片段选择面板。

```ts
let journal: BrowserWindow | undefined;
function openJournal() {
  if (journal && !journal.isDestroyed()) {
    if (journal.isMinimized()) journal.restore();
    journal.focus();
    return;
  }
  journal = new BrowserWindow({
    title: '渚的手账', width: 420, height: 320, autoHideMenuBar: true,
    webPreferences: { sandbox: true, nodeIntegration: false, contextIsolation: true },
  });
  journal.on('closed', () => { journal = undefined; });
  void journal.loadURL(MAIN_WINDOW_WEBPACK_ENTRY + '#journal');
}
```

把 `src/renderer.ts` 最后的挂载语句换成：

```ts
const journalPage = window.location.hash === '#journal';
createRoot(container).render(journalPage
  ? h('main', { className: 'journal' }, h('h1', null, '渚的手账'),
      h('p', null, '古河渚'), h('p', null, '轻点渚可以打招呼，按住她可以拖动。'),
      h('p', null, '想把她带回主屏时，在系统托盘选择「找回角色」。'))

```

给 `.journal` 设置 `box-sizing: border-box; height: 100%; overflow: auto; padding: 24px; background: #fff8ed; color: #50392e;`。它只在手账窗口中生效。托盘“退出桌宠”继续调用已有的 `app.quit()`，即使手账打开也能退出整个程序。

## 7. 最终验收

在 `nagisa-app` 目录运行 `npm.cmd run typecheck`，通过后重新运行 `npm.cmd start`。修改了主进程或 preload 时，先结束旧开发服务再启动。以下表格可直接当作试玩记录：

| 检查 | 实际操作 | 通过标准 |
|---|---|---|
| 第一次开发回归 | 启动，切到普通应用，再从托盘操作 | 背景透明、角色置顶、托盘可用 |
| 位置恢复 | 拖到主屏左侧，松手后立即从托盘退出，再开 | 角色出现在松手位置；有副屏时再测一次副屏重启 |
| 点击与拖动 | 单击一次；拖动 50 像素松手；再拖出一段距离并拖回起点松手 | 只有第一次出现问候；松手后移动鼠标，角色留在原地 |
| 动画切换 | 等待眨眼，中途单击，再连续点击五次 | 挥手能完整结束，气泡只有一个；4 秒后消失，随后恢复眨眼 |
| 穿透与隐藏 | 在记事本上方开启穿透并选择文字；再隐藏角色，选择“找回角色” | 底层可操作；找回后渚可见、可点击，穿透菜单取消勾选 |
| 多屏恢复 | 把渚放到副屏，断开副屏；另测关闭程序后断开副屏再启动 | 两种情况下都能在主屏看见完整角色。单屏机器可在关程序后备份位置文件，将 displayId 改成不存在的整数再启动，验证启动回退；热拔插单列为待实机验证 |
| 异常位置文件 | 退出后备份位置文件，暂时把内容改为无效 JSON，然后启动 | 正常出现在主屏；重新拖动并退出后，位置文件恢复为有效 JSON |
| 手账生命周期 | 连续两次点“打开手账”，关闭手账；再打开，选“退出桌宠” | 只有一个手账窗口；关手账后渚可互动；退出时两个窗口及托盘一起消失 |

**排错顺序**：拖得动但点不出气泡，先查旧的两条 `app-region: drag` 是否都已移除。点了没反应，在角色窗口的开发者工具检查 `typeof window.pet?.finish` 是否为 `"function"`，再核对 preload 与主进程的通道名。角色有时卡在某一帧，检查是否存在第二条动画定时链。手账打开却看见角色，检查加载地址是否带 `#journal`。
