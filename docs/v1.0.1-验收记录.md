## 实测

| 检查项 | 结果 |
| --- | --- |
| 轻点与起拖 | 长按静止保持原姿势。移动 5 个逻辑像素后松手仍问候，移动 6 个进入提起姿势且不增加好感。仅松手坐标越过阈值时，没有闪现拖动图。 |
| 朝向与抖动 | 左、右、竖直分别显示左向、右向和中性。竖直起拖后横移 6 像素转右。向右 40 后退 2 保持朝右，再退 4 转左。按住静止超过 2 秒仍保留朝向。 |
| 衣角与显示 | 五张图均为 512 × 512、8 位 RGBA。浅色和深色背景下能辨清衣角和悬垂轮廓。用局部放大和衣角高光中心估算，五帧受力点最大间距约 1.5 个原图像素。 |
| 取点、边界与重启 | 从角色靠边处起拖，窗口移动量与指针位移一致。用 Windows 鼠标事件拖至工作区边缘，指针移到角色窗口外再松手，窗口保持在工作区内且提起图撤下。重启恢复拖动后的坐标。 |
| 设置与中断 | 锁定及禁拖时大幅划动不会提起或问候。拖动中切换锁定、禁拖或穿透，按快捷键隐藏或找回，以及模拟丢失指针捕获，均能撤下提起图并允许下一次拖动。穿透后的点击由桌宠下方的测试窗口收到。替换存档也会结束当前手势。 |
| 动作与进度 | 提起时温习到期，学习点由 6 升到 9，记录只写一次。短拖后接回进食和抱玩偶的当前帧，面包只扣一个。 |
| 缩放与动效 | 在 100% 和 150% 角色缩放下验证左、右摆动。12、24、30 帧上限下均按两帧交替显示。减少动态效果开启时，各朝向稳定保持代表帧。 |
| 旧版续用 | 在 v1.0.0 中使用同一测试档并保存位置，再启动 v1.0.1。团子币 54、好感 21、4 个小面包、团子玩偶、桌面设置和坐标均保留。 |
